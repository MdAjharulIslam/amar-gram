# 🌿 Amar Gram – আমার গ্রাম

### শেকড়ের টানে, প্রিয় খলাপাড়া ❤️
**Our Village, Our Pride.**

Amar Gram (আমার গ্রাম) is a modern, responsive and community-focused web application developed to create a digital identity for our beloved village, **খলাপাড়া (Khalapara)**.

গ্রাম শুধু একটি ভৌগোলিক স্থান নয়, গ্রাম মানে শৈশবের স্মৃতি, মাটির গন্ধ, সবুজ প্রকৃতি, পরিচিত মুখ আর অসংখ্য আবেগের গল্প। সময়ের পরিবর্তনের সঙ্গে সঙ্গে আমাদের গ্রামও এগিয়ে যাচ্ছে। সেই পরিবর্তনের ধারায় প্রযুক্তির মাধ্যমে গ্রামের সৌন্দর্য, ঐতিহ্য, ইতিহাস, গুরুত্বপূর্ণ স্থান এবং মানুষের মধ্যে যোগাযোগ আরও সহজ করাই Amar Gram-এর মূল লক্ষ্য।

এই platform-এর মাধ্যমে গ্রামের মানুষ দেশ-বিদেশের যেকোনো জায়গা থেকে নিজেদের গ্রামের তথ্য, ছবি, স্মৃতি এবং প্রয়োজনীয় যোগাযোগের তথ্য সহজেই খুঁজে পেতে পারবেন।

## 🌟 About The Project | প্রজেক্ট সম্পর্কে

Amar Gram is more than just a village website. এটি একটি digital community platform, যেখানে গ্রামের পরিচয়, ঐতিহ্য, প্রকৃতি এবং মানুষের গল্প এক জায়গায় তুলে ধরা হয়েছে।

আমাদের গ্রামের অনেক সুন্দর জায়গা, ঐতিহাসিক স্মৃতি, গুরুত্বপূর্ণ ব্যক্তিত্ব এবং অসংখ্য মুহূর্ত সময়ের সঙ্গে হারিয়ে যেতে পারে। এই website-এর মাধ্যমে সেগুলোকে digital form-এ সংরক্ষণ করার একটি ছোট্ট উদ্যোগ নেওয়া হয়েছে।

**The main objectives are:**

- গ্রামের একটি সুন্দর ও আধুনিক digital identity তৈরি করা।
- গ্রামের ইতিহাস, ঐতিহ্য এবং সংস্কৃতি সংরক্ষণ করা।
- গ্রামের গুরুত্বপূর্ণ স্থানগুলো সবার সামনে তুলে ধরা।
- জরুরি প্রয়োজনে প্রয়োজনীয় তথ্য সহজে পাওয়া নিশ্চিত করা।
- Blood donor information-এর মাধ্যমে মানুষের পাশে দাঁড়ানো।
- গ্রামের মানুষের মধ্যে যোগাযোগ ও সামাজিক বন্ধন আরও শক্তিশালী করা।
- গ্রামের স্মৃতি ও সুন্দর মুহূর্তগুলো ভবিষ্যৎ প্রজন্মের জন্য সংরক্ষণ করা।

## ✨ Key Features | প্রধান বৈশিষ্ট্যসমূহ

### 🏡 1. Village Introduction – আমাদের গ্রামের পরিচয়

আমাদের গ্রামের পরিচয় এবং সৌন্দর্য তুলে ধরার জন্য রয়েছে একটি সুন্দর introductory section।

**What you'll find:**
- গ্রামের সংক্ষিপ্ত পরিচিতি।
- গ্রামের প্রকৃতি, পরিবেশ ও ঐতিহ্যের গল্প।
- সবুজ ধানক্ষেত, গ্রামের মেঠো পথ এবং প্রাকৃতিক সৌন্দর্যের ছবি।
- Beautiful hero section with attractive typography and visuals.
- গ্রামের প্রতি ভালোবাসা ও আবেগ প্রকাশের একটি সুন্দর presentation।

এটি visitors-দের আমাদের গ্রামের সঙ্গে পরিচিত হওয়ার প্রথম সুযোগ তৈরি করে।

### 📍 2. Important Places – গ্রামের গুরুত্বপূর্ণ স্থান

প্রতিটি গ্রামেরই কিছু বিশেষ জায়গা থাকে, যেগুলোর সঙ্গে জড়িয়ে থাকে মানুষের স্মৃতি, ইতিহাস ও আবেগ।

এই section-এ গ্রামের গুরুত্বপূর্ণ স্থানগুলো সুন্দর image cards-এর মাধ্যমে উপস্থাপন করা হয়েছে।

**Features:**
- Image-based location cards.
- Interactive horizontal slider.
- প্রতিটি স্থানের জন্য আলাদা details page।
- Location-specific images and descriptions.
- Responsive card layout for mobile and desktop.

প্রতিটি স্থানের বিস্তারিত তথ্য আলাদা page-এ দেখার সুযোগ রয়েছে, যাতে visitors সহজেই জায়গাগুলো সম্পর্কে জানতে পারেন।

### 🩸 3. Blood Donor Directory – রক্তদাতা খুঁজুন

রক্তের প্রয়োজন কখনো বলে আসে না। জরুরি মুহূর্তে একজন রক্তদাতা খুঁজে পাওয়া অনেক সময় কঠিন হয়ে পড়ে।

এই section-এর উদ্দেশ্য হলো গ্রামের স্বেচ্ছায় রক্তদান করতে আগ্রহী মানুষদের তথ্য সহজে খুঁজে পাওয়ার সুযোগ তৈরি করা।

**Features:**
- Blood donor information display.
- Blood group-based information.
- Donor contact information.
- Randomized donor card arrangement.
- Interactive donor slider.
- Mobile-friendly donor cards.

আমাদের ছোট্ট উদ্যোগ হয়তো কারও জরুরি মুহূর্তে অনেক বড় সহায়তা হয়ে উঠতে পারে।

*এক ব্যাগ রক্ত, বাঁচাতে পারে একটি প্রাণ।*

### 🚨 4. Emergency Information – জরুরি প্রয়োজনে

জরুরি মুহূর্তে প্রয়োজনীয় যোগাযোগের তথ্য দ্রুত পাওয়া অত্যন্ত গুরুত্বপূর্ণ।

এই section-এ গ্রামের মানুষের প্রয়োজনীয় emergency information এবং গুরুত্বপূর্ণ যোগাযোগের তথ্য সহজে access করার ব্যবস্থা রাখা হয়েছে।

**Highlights:**
- Important emergency contacts.
- Useful contact information.
- Quick access to essential information.
- Simple and user-friendly interface.

লক্ষ্য একটাই—প্রয়োজনের সময় যেন গুরুত্বপূর্ণ তথ্য খুঁজতে বেশি সময় নষ্ট না হয়।

### 👥 5. Respected Personalities – সম্মানিত ব্যক্তিবর্গ

একটি গ্রামের পরিচয় শুধু তার প্রকৃতিতে নয়, সেই গ্রামের মানুষের মধ্যেও নিহিত।

যেসব মানুষ নিজেদের কাজ, অবদান, সম্মান ও ভালোবাসা দিয়ে গ্রামের পরিচয়কে সমৃদ্ধ করেছেন, তাঁদের পরিচিতি তুলে ধরার জন্য রয়েছে এই section।

**Features:**
- Profile-based presentation.
- Personal photographs.
- Individual information and descriptions.
- Beautiful responsive profile cards.

আমাদের গ্রামের গর্বিত মানুষদের সম্মান জানানো এবং তাঁদের অবদান স্মরণে রাখাই এই section-এর উদ্দেশ্য।

### 📸 6. Memories Album – স্মৃতির অ্যালবাম

কিছু মুহূর্ত কখনো পুরোনো হয় না। সময় চলে যায়, কিন্তু স্মৃতিগুলো থেকে যায়।

এই section-এ গ্রামের বিভিন্ন সময়ের ছবি, অনুষ্ঠান, উৎসব এবং প্রাকৃতিক সৌন্দর্যের মুহূর্তগুলো album আকারে সংরক্ষণ করা হয়েছে।

**Album Categories:**
- 🌿 প্রকৃতি (Nature)
- 🎉 উৎসব (Festivals)
- 🎊 অনুষ্ঠান (Events)
- ❤️ স্মৃতি (Memories)

**Features:**
- Interactive photo albums.
- Category-based filtering.
- Beautiful image gallery.
- Full-screen image viewing.
- Easy album navigation.
- Close button for image viewing.
- Responsive gallery layout.

এটি শুধু একটি photo gallery নয়; বরং আমাদের গ্রামের অতীত ও বর্তমানকে একসঙ্গে ধরে রাখার একটি digital archive।

### 🎵 7. Background Music – গ্রামের আবহ

Website browsing experience আরও সুন্দর ও আবেগপূর্ণ করার জন্য রয়েছে background audio functionality।

**Features:**
- Background music playback.
- Audio toggle control.
- User-controlled listening experience.

গ্রামের পরিবেশ ও স্মৃতির সঙ্গে মিল রেখে website-এ একটি সুন্দর browsing atmosphere তৈরি করার চেষ্টা করা হয়েছে।

### 📱 8. Fully Responsive Design

Amar Gram is designed to provide a smooth experience across different screen sizes and devices.

**Responsive support:**
- Desktop computers.
- Laptops.
- Tablets.
- Android smartphones.
- iPhones.

প্রতিটি section, card, image এবং navigation বিভিন্ন screen size অনুযায়ী optimize করা হয়েছে।

## ⚙️ Installation & Setup

Want to run Amar Gram on your local machine? Follow these steps.

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd amar-gram
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in your browser**

```text
http://localhost:3000
```

Now you can explore the application locally!

## 🚀 Deployment

Amar Gram can be deployed using Vercel.

**Deployment Steps:**
1. Push the source code to GitHub.
2. Log in to Vercel.
3. Import your GitHub repository.
4. Configure the Next.js project.
5. Click Deploy.
